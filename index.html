LinchStone Privacy Policy

This policy applies to the LinchStone phone app and to LinchStone Helper on your Windows PC.

Last updated November 11, 2026

No LinchStone account or server

LinchStone is a phone remote for AI tools that already run on your computer. There is no LinchStone account and no LinchStone server.

How the phone and PC talk

The phone talks only to LinchStone Helper on a PC you control, on your home network or over a tunnel you set up (Tailscale, Headscale, or WireGuard). The PC has to stay on, awake, and running LinchStone Helper. A sleeping PC looks offline. The phone does not run the models.

Chat text, image prompts, photos you attach, and file browsing go to that PC. They are not sent to LinchStone.

Pairing keys

Pairing keys stay on the phone and the PC. Unpair, or erase phone data in Settings, to drop the pairing key and the phone’s copy. Files on the PC stay until you delete them there.

Cloud tools and API keys

If you add a cloud tool and run that step, the helper on your PC sends that step’s text, and a photo if that step needs one, to the provider you named (for example OpenAI, Anthropic, or Gemini). Prompts for a cloud tool leave the PC only to the provider you added. The key for that provider is encrypted on the PC with Windows DPAPI and is never sent to LinchStone. The phone does not keep a copy. Nothing is sent until you run the step. Local tools (LM Studio, ComfyUI, Amuse) stay on the PC.

Microphone and analytics

The optional microphone button uses Android’s speech recognizer to turn speech into text. LinchStone does not receive or store the audio.

The on-phone analytics switch is off unless you turn it on. Those analytics are counts only, and the counts stay on the phone.

Paid plans

Paid plans are sold by Google Play. LinchStone stores only which plan is active so it can apply the tool cap. It never sees your card.
